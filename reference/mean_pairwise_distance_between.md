# Mean pairwise distance between two disjoint subject sets.

Mean pairwise distance between two disjoint subject sets.

## Usage

``` r
mean_pairwise_distance_between(subject_ids1, subject_ids2, dist_matrix)
```

## Arguments

- subject_ids1:

  Character vector of subjects in set 1.

- subject_ids2:

  Character vector of subjects in set 2.

- dist_matrix:

  Symmetric distance matrix.

## Value

Scalar mean cross-set distance.
