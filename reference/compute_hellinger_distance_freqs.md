# Hellinger distance between two frequency vectors on a simplex.

Hellinger distance between two frequency vectors on a simplex.

## Usage

``` r
compute_hellinger_distance_freqs(freqs1, freqs2)
```

## Arguments

- freqs1:

  Numeric frequency vector (sums to 1).

- freqs2:

  Numeric frequency vector (sums to 1).

## Value

Scalar Hellinger distance in 0, 1.
